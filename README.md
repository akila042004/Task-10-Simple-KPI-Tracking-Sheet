Task 10 – Simple KPI Tracking Sheet

Project Overview

This project is a Simple KPI Tracking Sheet developed using Microsoft Excel and Google Sheets as part of my Veda Technology internship.

Objective

To create a one-page KPI summary that automatically tracks important business performance indicators using raw order data.

Tools Used

- Microsoft Excel
- Google Sheets
- GitHub

KPIs Tracked

- Total Revenue
- Total Units Sold
- Average Order Value
- Top Performing Product

Features

- Automatic KPI calculations
- SUMIFS and AVERAGEIFS formulas
- Organized raw order data
- Business performance summary
- Automatic updates when new data is added

Project Structure

- Raw Data
- KPI Summary
- Formulas and Calculations

Outcome

Successfully created a simple KPI tracking sheet to understand business performance through important key performance indicators.
